# База — приложение для базы знаний на Google Диске

Приложение на iPhone для твоей папки «База знаний» на Google Диске:

- **Записать** — текстовая заметка, ссылка на YouTube или статью (с комментарием), голосовая заметка. Всё уходит во «Входящие».
- **Голосовые** — Gemini сразу расшифровывает запись, текст ложится во «Входящие», аудио — в «Источники/Файлы».
- **База** — темы из «Знаний», «Мысли и идеи», мои заметки, поиск по названиям, чтение страниц прямо в приложении (без Google Docs).
- **Видео** — на каждое видео своя карточка: коротко о главном, стоит ли смотреть, главы и ключевые идеи с таймкодами, чек-лист «Что применить», цитаты, вопросы для самопроверки. Таймкод открывает плеер на нужной секунде. Статусы «Не смотрел / Посмотрел / Применил», фильтры по типу, теме и каналу.
- **AI** — чат с Gemini по твоей базе: сам находит нужные страницы и отвечает по ним со ссылками.
- Работает без сети: прочитанное сохраняется на телефоне, записанное уходит на Диск, как только появится интернет.

Раскладывает по темам всё та же утренняя ревизия (`dailyRevision` в Apps Script, 9:00 по Иркутску). В приложении есть кнопка «Разобрать сейчас». Весь AI — через твой ключ Gemini, токены Claude не тратятся.

## Как это устроено

```
iPhone (PWA «База»)  ──POST──►  Apps Script: Api.gs  ──►  Google Диск «База знаний»
                                      │                      Входящие / Знания / Мысли и идеи / Источники
                                      └──► Gemini API (тот же GEMINI_API_KEY, что у ревизии)
```

- `apps-script/Code.gs` — ежедневная ревизия «Входящих» (была раньше, доработана под карточки видео).
- `apps-script/Video.gs` — карточки видео: транскрипт и конспект в фоне сразу после добавления ссылки.
- `apps-script/Api.gs` — API для приложения. Все три файла лежат в **одном** проекте Apps Script и пользуются функциями друг друга.

## Карточки видео

Ссылка на YouTube → во «Входящих» появляется заметка со ссылкой и комментарием, а в новом разделе **«Видео»** — карточка. Фоновая очередь (`processVideoQueue`) за 1–3 минуты:

1. берёт субтитры YouTube, а если их нет — Gemini сам слушает видео кусками по 10 минут (транскрипт — в «Источники/Клиппинги»);
2. делает по транскрипту конспект: коротко, стоит ли смотреть, главы, 5–12 идей с таймкодами, что применить, цитаты, вопросы для самопроверки, тип (обучение / вдохновение / развлечение) и темы.

Утренняя ревизия берёт готовую карточку и разносит полезное по «Знаниям» со ссылкой на карточку и таймкодами. Развлекательные видео остаются только карточкой.

Статус, тип, темы и отметки чек-листа хранятся в свойствах файла карточки на Диске, поэтому список с фильтрами грузится одним запросом.

Распознавание речи Gemini включено по умолчанию. Выключить можно свойством скрипта `TRANSCRIPT_FALLBACK` = `off`. Учти, что час видео — это сотни тысяч токенов Gemini, бесплатного лимита на это может не хватить.

Для видео, сохранённых до карточек: в приложении Настройки → «Сделать карточки для старых видео» (или функция `migrateVideos()` в редакторе). Пустые транскрипты («субтитров нет») и дубли переедут в «Служебное/Архив», удалено ничего не будет. Через 5–10 минут карточки будут готовы, ход обработки виден в Apps Script → «Выполнения».

## Обновление серверной части одной командой

Код Apps Script живёт в `apps-script/` и заливается через [clasp](https://github.com/google/clasp) (официальная консоль Google):

```bash
powershell -ExecutionPolicy Bypass -File tools/deploy-script.ps1
```

Команда заливает все файлы в проект (`.clasp.json` указывает, в какой) и переводит веб-приложение на новую версию — адрес `…/exec` не меняется. Описание версии берётся из последнего коммита, своё можно задать через `-Description "…"`.

Один раз на компьютере: `npm install -g @google/clasp`, `clasp login` под владельцем скрипта (burninp90) и включённый Apps Script API на [script.google.com/home/usersettings](https://script.google.com/home/usersettings).

Залитый так проект целиком заменяет код в редакторе: правки, сделанные прямо в редакторе Apps Script, перед этим нужно перенести в `apps-script/` (`clasp pull` скачает их).
- `app/` — само приложение (обычный сайт, без сборки). Его надо выложить на любой хостинг с HTTPS.
- `tools/` — генератор иконок и локальный сервер для просмотра.

## Установка (один раз, ~15 минут)

### 1. Apps Script

1. Открой [script.google.com](https://script.google.com) → проект с ревизией базы (там, где `Code.gs`).
2. «+» рядом с «Файлы» → «Скрипт» → назови `Api` → вставь содержимое `apps-script/Api.gs`. Так же добавь `Video` из `apps-script/Video.gs`, а `Code.gs` замени версией из `apps-script/Code.gs`. Сохрани.
3. Вверху выбери функцию `setupApp` → «Выполнить». В журнале появится **ключ приложения** — скопируй.
4. «Начать развертывание» → «Новое развертывание» → шестерёнка → «Веб-приложение»:
   - «Запуск от имени»: **я**
   - «У кого есть доступ»: **все** (без этого телефон не достучится; защищает ключ приложения)
5. «Развернуть», разреши доступы, скопируй **URL веб-приложения** (заканчивается на `/exec`).

Проверка: выполни `testApi()` — в журнале будет список тем.

> Дальше код обновляется одной командой — см. «Обновление серверной части одной командой». Вручную: «Начать развертывание» → «Управление развертываниями» → карандаш → «Версия: новая версия» → «Развернуть». URL не меняется.

### 2. Приложение в интернете

Уже выложено: **https://pavel13801.github.io/baza/**. Любое изменение в папке `app/` в ветке `main` публикуется само (GitHub Actions, `.github/workflows/pages.yml`). После выпуска новой версии поменяй `VERSION` в `app/sw.js`, чтобы телефон подтянул обновление.

В сайте нет ни ключей, ни данных — поэтому репозиторий публичный (бесплатный GitHub Pages работает только с публичными).

### 3. На iPhone

1. Открой адрес сайта в **Safari** → «Поделиться» → **«На экран „Домой“»**.
2. Запусти «Базу» с иконки → ⚙️ Настройки → вставь URL веб-приложения и ключ → «Сохранить и проверить».
3. Разреши микрофон при первой голосовой заметке.

### 4. Ссылки из YouTube в один тап (по желанию)

iOS не даёт сайтам появляться в меню «Поделиться», поэтому это делает «Быстрая команда»:

1. Приложение «Команды» → «+» → действие **«Получить содержимое URL»**.
2. URL — адрес веб-приложения (`…/exec`). Метод — **POST**. Текст запроса — **JSON**:
   - `action` → `add`
   - `token` → ключ приложения
   - `text` → переменная «Ввод быстрой команды»
3. ⓘ → «Показывать в меню „Поделиться“», типы входа: URL и текст. Назови «В базу».

Теперь в YouTube: «Поделиться» → «В базу». Можно и голосом: «Привет, Siri, в базу».

## Почему PWA, а не IPA

IPA без Mac не собрать, а подписанная бесплатным Apple ID живёт 7 дней (с платным аккаунтом за $99 в год — год). Приложение с экрана «Домой» не истекает вообще, обновляется само при выходе новой версии на сайте и умеет всё нужное: микрофон, офлайн, полноэкранный режим. Сайтам Safari чистит данные через 7 дней без посещений, но приложения на экране «Домой» под это правило не попадают. Если когда-нибудь понадобится именно App Store, эту же папку `app/` можно обернуть в Capacitor.

Чего PWA на iOS не умеет: работать в фоне (база обновляется при открытии и раз в N минут, пока приложение открыто) и пункта в меню «Поделиться» (его заменяет «Быстрая команда»).

## Gemini и токены

- Всё AI идёт через **Gemini API** по ключу из Google AI Studio (`GEMINI_API_KEY` в свойствах скрипта — тот же, что у ревизии). Claude Code в этом не участвует.
- Подписка Google AI Pro к API не относится: она даёт приложение Gemini, а API работает по ключу. У ключа есть бесплатный лимит, для личной базы его обычно хватает.
- На бесплатном тарифе Google может использовать отправленные данные для улучшения моделей. Для приватности включи оплату в AI Studio.
- Модель — свойство `GEMINI_MODEL` (или `CONFIG.MODEL` в `Code.gs`).

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «Нет связи с сервером» при рабочем интернете | Проверь URL (должен заканчиваться на `/exec`) и что доступ при развертывании — «все». |
| «Неверный ключ приложения» | Скопируй ключ заново: выполни `setupApp()`, он покажет текущий. |
| «Сервер ответил не JSON» | Развертывание старое или с доступом не «все» — создай новую версию развертывания. |
| Голосовая не расшифровалась | Запись всё равно лежит во «Входящих», её разберёт ревизия. Проверь ключ Gemini: `testGemini()`. |
| Новое не появилось в «Базе» | Ревизия раскладывает в 9:00. Кнопка «Разобрать» в «Базе» запускает её сразу (в течение минуты). |
| Ключ утёк | `resetAppToken()` — старый ключ перестанет работать. |

## Локальный просмотр

```bash
node tools/serve.js
```

Открой http://localhost:5173 → «База» → «Посмотреть демо». Иконки перерисовываются командой `node tools/make-icons.js`.
